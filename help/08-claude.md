# Working with Claude

Claude Desktop and Claude Code can work with your documents, using the Claude you already sign in to. No API key is needed.

1. [Open Connect Claude](#do=connect-claude).
2. Turn on **Let Claude work with my documents**.
3. Click **Add to Claude Desktop** or **Add to Claude Code**.
4. Restart Claude Desktop, or start a new Claude Code session.

Then ask Claude about the documents you have open.

## What Claude can do

- List and read documents open in a tab or in the open folder.
- Search the open folder, and see your highlights and notes.
- Suggest a change. You see it marked up here, and accept or reject it.

## What it can't do

- Change anything without your yes.
- Reach password-locked documents, or anything else on your computer.
- Reach anything while the app is closed or the connector is off.

The portable version can't use the connector, because it moves each time it runs.

**File → This Document → Open Folder in Claude Code** opens a terminal in the document's folder, running Claude Code.
