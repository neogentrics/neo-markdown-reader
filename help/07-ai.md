# Connecting an AI service

AI assist can summarize a document, explain a passage, proofread, rewrite, translate, draft flashcards, and answer questions about a folder. It's optional. Nothing is sent anywhere until you choose a service, turn it on and ask for something.

![The AI Assist Settings window, with a list of services, a place for a key, and a list of models.](guide/ai-services.png)

[Open AI Assist Settings](#do=ai-settings), turn on AI assist, then pick one of these.

## With Claude Code

If Claude Code is installed and signed in, choose **Claude Code**. It uses your Claude plan, and no key is needed.

## With an API key

Choose Claude, ChatGPT, Gemini, Mistral or OpenRouter, click **Get an API key**, and paste the key. Each service bills you directly. Your key is stored encrypted on this computer.

## With a model on your own computer

Install Ollama or LM Studio and download a model. Choose **On this computer** and click **Refresh list**. Nothing leaves your computer, and it works without internet.

## Using it

Find everything under **Edit → AI Assist**. Writing help appears as a marked-up change to accept or reject. Password-locked documents are never sent.

## Automations

Send documents to your own workflows: n8n, Make, Zapier, Home Assistant or a script of your own. Nothing is sent until you've seen what's going and where.

1. Choose *File → Automations → Manage Automations*, then **New Automation**.
2. Give it a name, paste the webhook's address, and choose what it sends and what happens with the answer.
3. Run it from *File → Automations* or Quick Open (`Ctrl+K`, then `>`). You can give it a shortcut too.

With n8n, add your address and API key in the same window and choose **List My Workflows** to pick one by name. The workflow must be active, with a Webhook node that takes POST. Use a *Respond to Webhook* node to send an answer back.

To let workflows open documents here, turn it on in [Preferences → Automations](#do=preferences:automate). It needs the key shown there, and any change to a file still asks you first. If n8n runs on another computer, tick **Also allow other computers on my network**.

Locked documents are never sent.
