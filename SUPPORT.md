# Getting help

**In the app.** Press `F1` for the Help Center. It has guides for everything, common questions and a troubleshooting
page, and it works offline.

**Something's wrong.** [Report a bug](https://github.com/neogentrics/neo-markdown-reader/issues/new?template=bug_report.yml). Include your version from *Help → About*
and the steps that cause it. A screenshot helps.

**You have an idea.** [Suggest a feature](https://github.com/neogentrics/neo-markdown-reader/issues/new?template=feature_request.yml). Check the
[roadmap](ROADMAP.md) first, since it may already be planned.

**It's a security problem.** Please don't open a public issue. Follow [SECURITY.md](SECURITY.md).

RT Markdown Reader is free, and support is on a best-effort basis.
